# Fumo Hop — redesigned

A Discord Components V2 attendance bot for Become Fumo and Scuffed Become Fumo, written in Python using discord.py and SQLite.

See [SETUP.md](SETUP.md) for installation, configuration and hosting.

## Redesigned attendance card

- Compact emerald-themed header and clean game title.
- Separate **attending** count and optional **in-game** player count, so neither is mistaken for the other.
- One green **I'm coming** button. Press once to join the attendance list; press again to remove yourself. No modal or confirmation popup.
- List of confirmed people with Discord avatars, truncated to five names plus a total for large parties.
- Discord-relative time until registration closes, with an automatic disabled state after one hour.
- **No Join game button, URL or deep link** on the card. Discord cannot reliably force Roblox to open and join an exact game instance with one interaction.
- Public `/hop` pings `@everyone` only on the initial post. Later edits never ping again.
- Active and previously saved cards are repainted using the new design on the first maintenance pass after restarting the bot.

## Commands

```text
/hop
/advanced hop game:bf
/advanced hop game:sbf
/advanced hop game:sbf private:loogi ori
```

`/hop` posts the attendance card to the designated server channel. `advanced hop` can instead send one shared invitation in private DMs to named people. The sender is automatically counted. Private attendees are restricted to invitees. Changes appear on all copies.

## Run locally

Create a `.env` from `.env.example`, insert your own bot token, guild ID and channel ID, then run:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python bot.py --check
.venv/bin/python bot.py
```

The user-facing theme is controlled through `config.json` → `appearance`. Layout and button logic are in `ui.py`; the decorative banner is generated by `card_art.py`. No image-generation dependencies are needed.

To retain existing attendance sessions when upgrading, **keep your own `data/attendance.sqlite3` and `.env`**. Do not run two bot instances on one database. The distributable ZIP excludes `.venv`, `.env`, and database files for portability and privacy.

## Verify

```sh
python -m unittest discover -s tests -v
python bot.py --check
```

The code was tested locally using discord.py 2.7.1. Live message rendering, Discord permissions and Roblox API access require testing in your own server.
